Como as versões funcionam

Cada relatório tem um endereço estável — /dossie/, /tramitacao/, /dificuldades/ — que sempre aponta para a versão mais recente. Cada versão também fica congelada no seu próprio endereço (/dossie/v5/, por exemplo) e nunca muda depois de publicada. Uma lista de todas as versões, com data, tamanho e código de conferência, garante que uma citação feita hoje continue verificável amanhã.3

Notas

  1. Os dados foram colhidos por requisições públicas e não autenticadas; as planilhas estão em CSV, e as contagens, em JSON. ↩
  2. O código de conferência é o hash SHA-256 do arquivo; a tabela mostra os seus primeiros 16 caracteres. O nome de cada arquivo aparece ao passar o cursor sobre o link. ↩
  3. O manifesto versoes.json traz, para cada versão, o SHA-256 completo, o tamanho em bytes e a data. ↩
